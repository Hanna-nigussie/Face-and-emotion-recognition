# 👁️ Face and Emotion Recognition

An AI and computer vision project that explores facial recognition and facial emotion analysis using Python. The project contains separate scripts for face recognition and emotion recognition.

## ✨ Features

- **Face Recognition:** Detects and recognizes faces using the implemented recognition approach.
- **Emotion Recognition:** Analyzes facial expressions to identify emotions.
- **Python-Based:** Uses Python for computer vision and recognition tasks.
- **Modular Scripts:** Keeps face recognition and emotion recognition in separate files for easier maintenance.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Hanna-nigussie/Face-and-emotion-recognition.git
```

### 2. Navigate to the Project

```bash
cd Face-and-emotion-recognition
```

### 3. Set Up a Virtual Environment (Optional)

```bash
python -m venv venv
```

On Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

Install the Python libraries required by the project:

```bash
pip install -r requirements.txt
```

If a `requirements.txt` file is not available, install the dependencies used in the source code before running the scripts.

### 5. Run the Project

For face recognition:

```bash
python "face recognition.py"
```

For emotion recognition:

```bash
python emotion.py
```

Follow any instructions displayed by the scripts.
